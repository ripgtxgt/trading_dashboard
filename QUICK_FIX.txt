========================================
  QUICK FIX - Start PM2 Services
========================================

PROBLEM: start_services.bat has encoding issues on Windows

SOLUTION: Use direct PM2 commands

========================================
STEP 1: Open Command Prompt (cmd.exe)
========================================

cd C:\trading_dashboard

========================================
STEP 2: Start all services with PM2
========================================

pm2 start ecosystem.config.js

========================================
STEP 3: Check service status
========================================

pm2 list

You should see 5 services running:
- trading-dashboard
- trading-bot
- telegram-bot
- websocket-server
- daily-report

========================================
STEP 4: View logs (if needed)
========================================

pm2 logs

========================================
ALTERNATIVE: Use pm2_start.bat
========================================

Simply double-click: pm2_start.bat

Or run in cmd:
cd C:\trading_dashboard
pm2_start.bat

========================================
USEFUL PM2 COMMANDS
========================================

View all services:
  pm2 list

View logs:
  pm2 logs

Stop all services:
  pm2 stop all

Restart all services:
  pm2 restart all

Delete all services:
  pm2 delete all

Save PM2 configuration:
  pm2 save

========================================
VERIFY DASHBOARD
========================================

After starting services, open browser:
  http://localhost:3000
  or
  https://cryptoalpha.vip

You should see the dashboard with data.
